# Banco de dados - FSR Saúde Digital

Implementação acadêmica em SQLite para demonstrar modelagem, restrições e manipulação SQL.

- `schema.sql`: criação das tabelas, chaves, restrições e índices.
- `seed.sql`: dados demonstrativos usados pelo MVP.
- `crud.sql`: exemplos de INSERT, SELECT, UPDATE e DELETE.

O banco físico (`fsr_saude.db`) é gerado automaticamente pelo `server.js` e não é versionado.
